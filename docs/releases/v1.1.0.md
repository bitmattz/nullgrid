# NULLGRID OS 1.1.0

Wi-Fi and Bluetooth pickers in the bar, working Bluetooth, and updates through pacman.

![Wi-Fi picker](https://raw.githubusercontent.com/bitmattz/nullgrid/v1.1.0/docs/screenshots/wifi-picker.png)

## Already running 1.0.0? Update, don't reinstall

1.0.0 systems can update in place: once, in a terminal,

```sh
curl -LO https://github.com/bitmattz/nullgrid/releases/download/repo/nullgrid-keyring-20261014-1-any.pkg.tar.zst
sudo pacman -U nullgrid-keyring-20261014-1-any.pkg.tar.zst
pacman-key --finger 3494FF826CBF4E4AB1E83049FD658A9D368049E7    # must show "NULLGRID packages"
sudo pacman -Syu
```

then log out and back in. After that, `nullgrid update` keeps the system current.
Details: [docs/UPDATING.md](https://github.com/bitmattz/nullgrid/blob/v1.1.0/docs/UPDATING.md).

## Download

| File | What |
|---|---|
| `nullgrid-1.1.0-x86_64.iso` | the live and install image (x86_64, UEFI and legacy BIOS, ~1.9 GB) |
| `SHA256SUMS` | its checksum |

```sh
sha256sum -c SHA256SUMS
sudo dd if=nullgrid-1.1.0-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
```

Live user `nullgrid`, password `nullgrid`. Install from the start menu (**Install NULLGRID**) or
with `sudo nullgrid-install`. Turn off Secure Boot. Systems installed from this ISO get updates
through pacman with no setup.

## What's new

- **Wi-Fi picker:** click the Wi-Fi icon in the bar. The networks in range (scanned while it's
  open) with signal bars and a lock on secured ones; click to connect, type the password right in
  the list; a wrong password shows and asks again; disconnect and forget saved networks. Also the
  wired link's state, and **MORE: NMTUI** for hidden networks, VPNs and enterprise Wi-Fi.
- **Bluetooth picker:** click the Bluetooth icon. Paired devices (connect or disconnect, battery
  level, forget) and devices in range (one click pairs, trusts and connects). Devices that need a
  PIN: `bluetoothctl`. Right click on either icon still turns the radio on or off;
  `nullgrid-shell wifi|bluetooth` opens the pickers from a keybind or terminal.
- **Bluetooth works:** BlueZ is installed and its service enabled (it starts when an adapter is
  present). In 1.0.0 the Bluetooth icon never appeared.
- **Updates through pacman:** a signed `[nullgrid]` repository; the `nullgrid-keyring` package
  trusts its key and adds it to pacman.conf. `nullgrid update` updates the system and NULLGRID,
  refreshes your configs, restarts the shell if needed, and says when to log out or reboot. With
  plain `sudo pacman -Syu`, configs refresh at the next login.
- **Hotspots:** `dnsmasq` is included, so NetworkManager's hotspot and connection sharing work.

Full list: [CHANGELOG.md](https://github.com/bitmattz/nullgrid/blob/v1.1.0/CHANGELOG.md).

## How it was tested

- `make test` (257 unit and snapshot tests) and `make test-shell` (both pickers with fake
  networks and devices in a headless Sway).
- `make test-boot`: the live ISO, including the Wi-Fi picker joining a real NetworkManager hotspot
  on two virtual radios (`mac80211_hwsim`): wrong password first, then the right one.
- `make test-install`: install to a VM disk, boot it on UEFI and BIOS; the installed system has
  the update repository set up and syncs it from GitHub.
- `make test-upgrade`: the published 1.0.0 ISO installed, then updated to 1.1.0 by the steps
  above; versions, pickers, Bluetooth and the config refresh checked.
- Signed repository: pacman refuses a package or a package list that was changed after signing.
- `make perf`: idle desktop 726 MiB (Hyprland) / 590 MiB (lite) in a 4 GB VM without 3D,
  unchanged from 1.0.0.

## Known limitations

- Still tested in virtual machines only. Real Wi-Fi hardware and real Bluetooth pairing haven't
  run yet (the VM has neither; Bluetooth was tested with fake devices), nor NVIDIA GPUs.
- Bluetooth devices that ask for a PIN or passkey must be paired with `bluetoothctl`.
- No Secure Boot, no dual boot in the installer, x86_64 only.
