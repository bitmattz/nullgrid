# NULLGRID OS 1.0.0

The first release of NULLGRID: a lightweight, terminal-first Arch Linux system with a cyberpunk
HUD look. Dark crimson, neon cyan, chamfered frames, live system widgets and synthesized UI
sounds, all driven by one config file and switchable live.

![Desktop](https://raw.githubusercontent.com/bitmattz/nullgrid/v1.0.0/docs/screenshots/desktop-hyprland.png)

## Download

| File | What |
|---|---|
| `nullgrid-1.0.0-x86_64.iso` | the live and install image (x86_64, UEFI and legacy BIOS, ~1.9 GB) |
| `SHA256SUMS` | its checksum |

Verify the download, then write it to a USB stick (this erases the stick: check the device name
with `lsblk` first):

```sh
sha256sum -c SHA256SUMS
sudo dd if=nullgrid-1.0.0-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
```

Or boot it in a VM: QEMU/KVM with virtio-gpu (with 3D/virgl if you can), or VirtualBox with
"Enable 3D Acceleration" on. 4 GB of RAM recommended. Turn off Secure Boot: the image isn't signed.

## The live session

The ISO boots through an animated splash straight into the desktop (user `nullgrid`, password
`nullgrid`, shown on the lock screen; `sudo` needs no password). Things to try:

```sh
nullgrid theme set ice-protocol   # restyle everything live: terminal, bar, widgets, borders, GTK/Qt apps, lock screen
nullgrid theme set toxic-grid
nullgrid sound test all           # hear the sound pack (nullgrid sound set minimal-ops)
nullgrid keys                     # every keybind (or SUPER+/)
nullgrid mode tty                 # log in to the console dashboard instead of the desktop
nullgrid perf                     # what the desktop costs, per component
```

`SUPER+ENTER` terminal, `SUPER+SPACE` start menu, `SUPER+D` launcher, `SUPER+CTRL+L` lock.

## Installing

Start menu → **Install NULLGRID**, or `sudo nullgrid-install`. A text-mode installer asks for
the disk (erased; optional LUKS2 encryption), your user and hostname, keyboard, language, time
zone and GPU drivers. It copies the live system to the disk, so it needs no network (only extra
GPU drivers are downloaded), and takes a few minutes. The disk boots on UEFI and BIOS machines
alike. The first login runs a short wizard: theme, sound pack, desktop or terminal mode.
Details: [docs/INSTALL.md](https://github.com/bitmattz/nullgrid/blob/v1.0.0/docs/INSTALL.md).

## What's in it

- **Desktop:** Hyprland (Sway as fallback and for the `lite` profile), with the NULLGRID shell
  in Quickshell: status bar, dock, HUD widgets (RAM gauge, per-core CPU bars, network graph,
  workspace strip, activity grid), start menu, notifications, and a HUD lock screen (hyprlock).
  Procedurally generated wallpaper with circuit traces, logo plate, data blocks and keymap, at any
  resolution.
- **Terminal first:** kitty, zsh with autosuggestions and syntax highlighting, starship, fastfetch
  with the NULLGRID logo, and themed btop, yazi, neovim, lazygit, cava and tmux.
- **TTY mode:** a themed Linux console (Terminus font, theme palette) with a Textual dashboard
  (CPU, memory, network, system, app launcher), selectable at the greeter or with `nullgrid mode tty`.
- **One config, live:** `~/.config/nullgrid/nullgrid.toml` drives 32 generated configs (Hyprland,
  Sway, shell, kitty, starship, btop, nvim, GTK 3/4, Qt, icons, cursors, lock screen, console
  palette, ...). Three themes: `crimson-hud` (default), `ice-protocol`, `toxic-grid`. `nullgrid
  doctor` checks the whole setup.
- **Sound:** a small daemon (`nullgrid-sfx`) plays original, synthesized sounds on PipeWire for
  workspace switches, windows, notifications, volume, USB devices, battery, lock, screenshots,
  and optionally failed or long shell commands. Two packs: `neural-link` and `minimal-ops`.
  Mute, quiet hours and per-event volume.
- **Visual coverage:** GTK and Qt apps follow the theme live (Firefox, Thunar, Ristretto,
  zathura included), with an original line-icon theme and cursor set generated from the palette.
  Plymouth boot splash, greetd + tuigreet login screen.
- **Installer** and **first-run wizard**: see above.

Base: Arch Linux (archiso), Linux 7.2, systemd, Wayland only, PipeWire + WirePlumber.
All art, icons, sounds and wallpapers are original or open-licensed
([assets/LICENSES.md](https://github.com/bitmattz/nullgrid/blob/v1.0.0/assets/LICENSES.md)).

## Measured

In a 4 GB QEMU/KVM VM without 3D (software rendering, the worst case), idle desktop:

| | Memory used | Widgets (shell) CPU |
|---|---:|---:|
| Hyprland (default) | 718-738 MiB | 0.2% of a core |
| Sway (`lite` profile) | 585-608 MiB | 0.1-0.15% of a core |

Power-on to desktop in that VM: about 15 s. Method and details:
[docs/PERFORMANCE.md](https://github.com/bitmattz/nullgrid/blob/v1.0.0/docs/PERFORMANCE.md).

## How it was tested

Every check runs headless in Docker with QEMU/KVM, from the repo:

- `make test`: 253 unit and snapshot tests (theme engine, templates, sound generator and daemon,
  icons and cursors, dashboard, the installer's whole plan against a fake system, its TUI and
  the wizard).
- `make test-shell`: the shell and GTK/Qt apps in a headless Sway, checked by pixels across a
  live theme switch.
- `make test-boot`: boots the ISO and checks systemd, the Hyprland desktop, a live theme switch,
  sound coming out of the VM's sound card, the lock screen, GTK/Qt apps and Firefox, the Sway
  session, TTY mode and the greeter.
- `make test-install`: installs the ISO to a blank virtual disk unattended, boots it with UEFI
  (logs in through the greeter, takes the wizard into TTY mode) and with legacy BIOS. Also run
  with LUKS encryption, typing the passphrase into the splash.
- `make perf`: the measurements above.

## Known limitations

- **Tested in virtual machines only** (QEMU/KVM, plus early VirtualBox checks), not yet on real
  hardware. In particular the NVIDIA paths (proprietary driver, hybrid laptops with
  `nvidia-prime`) have never run on an NVIDIA GPU. Reports welcome.
- **NULLGRID's own packages don't update through pacman in 1.0.0.** *Since 1.1.0 they do:* see
  [docs/UPDATING.md](https://github.com/bitmattz/nullgrid/blob/main/docs/UPDATING.md) for the
  one-time setup on 1.0.0 systems. A big Hyprland update from Arch could also need config changes.
- **No Secure Boot** (unsigned boot loaders), **no dual boot** or manual partitioning in the
  installer (it takes the whole disk), no swap partition.
- Without a 3D-capable GPU, the desktop draws in software: it works, but blur is off and widgets
  update every 2 s instead of 1 s.
- x86_64 only. A Raspberry Pi image is planned.

## Build it yourself

Any Linux host with Docker: `make iso`, then `make run` (needs QEMU and OVMF on the host) or
the headless tests. See [docs/BUILDING.md](https://github.com/bitmattz/nullgrid/blob/v1.0.0/docs/BUILDING.md).
